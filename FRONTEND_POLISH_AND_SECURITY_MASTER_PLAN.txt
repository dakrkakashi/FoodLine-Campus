SECTION 3: DEFENSIVE UI ARCHITECTURE (React Snippets Reference)
================================================================================

1. CONDITIONAL AUTH GATING (isLoggedIn ? <Dashboard /> : <Login />)
   - Profile & Orders gate unauthenticated users cleanly to /login?redirect=...
   - Logged-in state on /profile and /orders shows personalized student banner:
     "Welcome back, [Student Name]! (PRN: [1031])"

2. LOADING STATE (isLoading && <Loader />)
   - Consistent loader spinner + animated brand icon during API fetches.
   - Prevents flashing unstyled content (FOUC).

3. ERROR STATE & INLINE RETRY (hasError && <ErrorMessage />)
   - Standard error view with red alert banner and "Retry Request" button.
   - Preserves form inputs so students do not retype data on network drop.

SECTION 4: Z+ SECURITY & AUTHENTICATION PROTOCOLS (ankurdecodes reels)
================================================================================

1. LIMIT THE LOGIN RATE (Brute-force prevention)
   - Backend rate limiter restricts student login attempts to 10/min.
   - OTP requests throttled to 5 per 15 minutes per device/phone.

2. HASH & ENCRYPT ALL PASSWORDS (Bcrypt / Supabase Auth)
   - Zero plain-text passwords stored anywhere in Supabase Postgres.
   - Industry-standard salted Bcrypt hashing with cost factor >= 10.

3. USE GENERIC ERROR MESSAGES (Anti-User Enumeration)
   - When login fails: "Invalid PRN or password. Please check your credentials."
   - Never expose "User does not exist" or "Incorrect password for Shivam".

4. DON'T REINVENT NAIVE AUTH
   - Auth is delegated to Supabase Auth engine with JWT stateless verification
     and hardened httpOnly cookies where supported.
