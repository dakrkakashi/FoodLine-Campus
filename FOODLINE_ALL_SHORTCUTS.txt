1. ⚡ GLOBAL "fl" COMMANDS (Run from ANY terminal directory)
--------------------------------------------------------------------------------
The "fl" CLI is installed globally at ~/.local/bin/fl. You can run these commands
from anywhere in your system:

  fl up
    👉 Master 1-Click Startup.
       - Kills stale processes on port 3000 & 4000.
       - Prints the latest checkpoint from PROJECT_MEMORY.md.
       - Boots Backend Express API (:4000) & Frontend Next.js (:3000) in background.
       - Launches Antigravity & OpenCode into their respective worktrees.

  fl check
    👉 Full Dual-Build Verification (The Zero-Error Guarantee).
       - Runs "npm --prefix frontend run build" (all 27 routes).
       - Runs "npm --prefix backend run build" (TypeScript compile).

  fl memory
    👉 Instant Session Memory.
       - Prints PROJECT_MEMORY.md directly to your terminal so you always know
         where you left off and what the next tasks are.

  fl ports
    👉 Check Port Status.
       - Shows if ports 3000 (Frontend) or 4000 (Backend) are in use or free.

  fl kill
    👉 Emergency Port Killer.
       - Instantly terminates any hanging processes occupying port 3000 or 4000.

  fl health
    👉 Deep System & Database Health Check.
       - Pings Express Backend (:4000) and live Supabase PostgreSQL connection.

  fl save "commit message"
    👉 1-Click GitHub Sync.
       - Stages, commits, and pushes all changes directly to GitHub remote.

2. 🐟 FISH SHELL ALIASES (Super-Fast Typing Shortcuts)
--------------------------------------------------------------------------------
Configured in ~/.config/fish/config.fish. Just open your terminal and type:

  Navigation Shortcuts:
    cd-fl        👉 Jumps directly to Main Project Folder (PPT OTHER TASKES)
    cd-be        👉 Jumps directly to Backend Worktree (FoodLine-Backend on branch 'backend')
    cd-fe        👉 Jumps directly to Frontend Worktree (FoodLine-Frontend on branch 'frontend')

  Dev & Build Shortcuts:
    check        👉 Runs full dual build check (Frontend + Backend)
    check-ports  👉 Checks if ports 3000 & 4000 are clean
    kill-ports   👉 Forcibly frees ports 3000 and 4000 (fuser -k 3000/tcp 4000/tcp)
    fl-save      👉 Commits & pushes all project changes to GitHub
