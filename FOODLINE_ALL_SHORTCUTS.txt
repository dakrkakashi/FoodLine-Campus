1. ⚡ GLOBAL "fl" COMMANDS
================================================================================
📍 WHERE TO RUN:
   Inside ANY Terminal window (Alacritty, Fish, Bash, etc.) from ANY directory!
   (You do NOT need to be inside the project folder — it works everywhere).

--------------------------------------------------------------------------------
Command: fl up
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Subah ya session ke start mein jab kaam shuru karna ho.
💡 WHAT IT DOES:
   1. Purane atke huye ports (3000 aur 4000) ko automatic kill karta hai.
   2. PROJECT_MEMORY.md se active session memory read karke terminal pe dikhata hai.
   3. Backend Express API (:4000) aur Frontend Next.js (:3000) background mein boot karta hai.
   4. Dono AI Agents (Antigravity IDE Backend aur Antigravity CLI agy Frontend) ko unke respective worktrees mein launch karta hai.

--------------------------------------------------------------------------------
Command: fl check
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Koi bhi code change karne ke baad, ya GitHub par push karne se pehle.
💡 WHAT IT DOES:
   - Frontend Next.js 15 ke saare 27 routes compile karke verify karta hai.
   - Backend Express + TypeScript ko compile karke zero error check karta hai.
   - Agar 0 error hain, tabhi code ready maanta hai (Compilation Guarantee).

--------------------------------------------------------------------------------
Command: fl apk
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Jab Android phone ke liye installable APK generate karni ho.
💡 WHAT IT DOES:
   - Capacitor aur Android SDK Build-Tools ke through native debug APK compile karta hai.
   - Ready `.apk` file automatically Desktop par save kar deta hai: ~/Desktop/FoodLine_Campus.apk.

--------------------------------------------------------------------------------
Command: fl memory
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Jab bhi confuse ho jao ki "Maine last time kya kiya tha aur aage kya karna hai?"
💡 WHAT IT DOES:
   - PROJECT_MEMORY.md ko terminal par print karta hai.
   - Dikha deta hai ki kaunse milestone complete huye aur agla mission kya hai.

--------------------------------------------------------------------------------
Command: fl ports
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Check karne ke liye ki port 3000 (Frontend) aur 4000 (Backend) free hain ya busy.
💡 WHAT IT DOES:
   - Port 3000 aur 4000 ka live status scan karke bataata hai.

--------------------------------------------------------------------------------
Command: fl kill
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Jab terminal mein error aaye "Port 3000 already in use" ya "EADDRINUSE: 4000".
💡 WHAT IT DOES:
   - 1 second ke andar dono ports ko forcibly free kar deta hai.

--------------------------------------------------------------------------------
Command: fl health
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Check karne ke liye ki Supabase PostgreSQL database aur Express backend online hain ya nahi.
💡 WHAT IT DOES:
   - Live backend aur Supabase server ko ping karke connection health verify karta hai.

--------------------------------------------------------------------------------
Command: fl save "tumhara commit message"
--------------------------------------------------------------------------------
🎯 WHEN TO USE:
   Kaam khatam hone ke baad jab sab kuch GitHub par cloud backup karna ho.
💡 WHAT IT DOES:
   - Saari modified files ko stage karta hai, commit banata hai, aur GitHub `main` pe push karta hai.
