# 🎨 FoodLine Frontend Application

Specialist Owner: **OpenCode (Frontend Design Specialist)**  
Target Campus: **Sanjivani University, Kopargaon (Cafe @7 Pilot)**

## 🚀 Overview
The FoodLine frontend is built with **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS**, and **Motion**.

### 📱 Pages & Features:
- `/` — Discovery Landing Hub with ambient glows & 4 core value pillars.
- `/menu` — Interactive 44-dish menu catalog with category filter tabs, search, dietary badges, and sticky cart tray.
- `/checkout` — Express checkout with 10-minute break slot capacity meter, direct standee UPI QR modal, and 12-digit UTR input.
- `/order/[token]` — Express Pickup Pass with optical QR code, 4-digit glowing OTP, and live SSE cooking stepper.
- `/kds` — Kitchen Display System 4-column kanban board with Web Audio ticket alerts & 1-tap stockout manager.
- `/admin` — Merchant Analytics Dashboard with SLA benchmarks, kitchen velocity, and slot capacity graphs.
- `/login` — Sanjivani University Google SSO & PRN/Phone OTP authentication screen.

## 🛠️ Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Run frontend dev server
npm run dev

# Opens on http://localhost:3000
```
