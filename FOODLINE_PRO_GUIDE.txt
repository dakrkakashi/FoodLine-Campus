PART 2: HOW TO IMPROVE QUALITY OF WORK & MANAGEMENT
================================================================================

The #1 mistake beginners make is saying: "Hey AI, build my entire startup!"
The AI gets confused and writes messy code.

Here is how smart Startup Founders manage their AI agents:

RULE 1: THE "ONE LEGO BRICK AT A TIME" RULE
-------------------------------------------
Never ask for 5 things together. Give ONE clear mission:
BAD PROMPT:  "Make payment page, add database table, fix css, and add sounds."
GOOD PROMPT: "Step 1: First just make the UPI QR Code popup look amazing."
Once done and tested, then say: "Step 2: Now add sound when payment succeeds."

RULE 2: THE "ASK BEFORE YOU CODE" RULE
--------------------------------------
Before letting the agent edit 10 files, tell it:
"Give me a quick 3-bullet plan of what files you will change before writing code."
This stops the AI from breaking existing working features!

RULE 3: THE "NEVER LEAVE A BROKEN TOY" RULE
-------------------------------------------
After every feature an agent builds, immediately run in terminal:
  npm run build:frontend
  npm run build:backend
If it says "Compiled successfully", you WIN!
If there is an error, tell the agent: "Fix this error right now before moving on."

RULE 4: THE 5-POINT QUALITY CHECKLIST FOR EVERY SCREEN
------------------------------------------------------
Whenever OpenCode creates a new page, check these 5 things in your browser:
[ ] Does it look good on Mobile Phone screen size? (Press Ctrl+Shift+M in Chrome)
[ ] Is the text clearly readable (dark mode / high contrast)?
[ ] Does the button show a loading spinner when clicked?
[ ] Does it give a green success popup if it works, or red if it fails?
[ ] Does it feel fast (less than 1 second to load)?

PART 3: WHAT WE REQUIRE FOR SUPERCHARGED PRODUCTIVITY (EXTENSIONS & PLUGINS)
================================================================================

To make your coding 10x faster and look ultra-clean, install these tools:

1. ESSENTIAL EXTENSIONS (Install from Extensions Tab in your IDE - Ctrl+Shift+X):
--------------------------------------------------------------------------------
a) "Tailwind CSS IntelliSense" (by Tailwind Labs) [FRONTEND]
   - Auto-suggests colors, borders, padding, and shadows automatically.

b) "Error Lens" (by Alexander) [UNIVERSAL]
   - Highlights syntax and type errors directly on the exact line in bold red!

c) "Prettier - Code Formatter" (by Prettier) [UNIVERSAL]
   - Press Ctrl+S (Save), and it instantly cleans up messy spacing and brackets.

d) "REST Client" or "Thunder Client" [BACKEND]
   - Test backend APIs (like /api/menu or /api/orders) with 1 click directly
     inside the editor without opening Postman or writing curl commands.

e) "GitLens — Git supercharged" [UNIVERSAL]
   - Shows you exactly which agent modified which line of code and when.

f) "Auto Rename Tag" + "Auto Close Tag" [FRONTEND]
   - When you rename an HTML/JSX tag (like <div> to <button>), it automatically
     renames the closing tag so you never have unclosed tag errors.

g) "Color Highlight" [FRONTEND]
   - Directly shows the actual color box next to hex codes in CSS/Tailwind.

h) "DotENV" [BACKEND/SECURITY]
   - Syntax highlights .env files and protects you from displaying raw secrets.

2. SPEED SHORTCUTS FOR YOUR TERMINAL (Fish Shell Aliases):
----------------------------------------------------------
Instead of typing long commands, add these shortcuts to your ~/.config/fish/config.fish:

   alias dev="cd '/home/darkkakashi/Desktop/StartUp Project (FOODLINE CAMPUS)/PPT OTHER TASKES' && npm run dev:frontend"
   alias api="cd '/home/darkkakashi/Desktop/StartUp Project (FOODLINE CAMPUS)/PPT OTHER TASKES' && npm run dev:backend"
   alias check="cd '/home/darkkakashi/Desktop/StartUp Project (FOODLINE CAMPUS)/PPT OTHER TASKES' && npm run build:frontend && npm run build:backend"
   alias save="git add . && git commit -m 'update' && git push origin main"

Now, whenever you want to test the app, you just type 3 letters:
`dev`   --> Starts Frontend on port 3000!
`api`   --> Starts Backend on port 4000!
`check` --> Tests both for zero compilation bugs!
`save`  --> Syncs everything to GitHub in 2 seconds!

PART 7: CAMPUS WI-FI & EDGE-CASE SIMULATION (THE 3 ACID TESTS)
================================================================================

Before you deploy to Sanjivani University, run these 3 Acid Tests:

TEST 1: THE "SLOW CAMPUS 3G" TEST
- In Chrome DevTools (F12) -> Network tab -> Change "No Throttling" to "Slow 3G".
- Now click around the app. Does it show smooth skeletons or does the screen freeze?
  (OpenCode must ensure loading skeletons are always shown!)

TEST 2: THE "61ST ORDER OVERFLOW" TEST
- Create orders until slot capacity hits 60/60.
- Try to place the 61st order.
- Result MUST be: HTTP 409 Conflict, "Slot is fully booked, please select next break."

TEST 3: THE "FAKE / REPLAY UTR" TEST
- Submit a valid 12-digit UTR payment (e.g. `928374615243`).
- Try to submit the EXACT same UTR number again for another order.
- Result MUST be: Replay Protection blocks it with "Duplicate transaction reference".
